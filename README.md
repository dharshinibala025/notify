# notify
1 Problem Statement There is a need for a user-controlled mobile assistant that can understand the content of eligible notifications, distinguish important information from low-priority noise, communicate urgent updates clearly and retain less urgent information for later review—while respecting privacy and Android platform limitations. 

2 Proposed Solution Notiq will capture notification information that Android makes available after the user grants notification access. It will perform local checks, send only eligible content to a secure backend for AI analysis, receive a structured interpretation, apply user-configured decision rules and either trigger a short voice announcement or save the result silently in notification history.
